# Tau Diffusion Simulation

A computational and interactive 3D simulation of misfolded tau-protein aggregation and diffusion, developed as a collaborative five-student research project through Boston University’s Research in Science & Engineering (RISE) program in Summer 2024.

## Project Overview

The project models how misfolded tau proteins may aggregate and spread through simplified three-dimensional brain regions.

We adapted mathematical models of tau production, aggregation, and diffusion from existing research and implemented them computationally to explore how changes in initial conditions and connectivity affect modeled tau propagation.

The model was designed to investigate factors including:

- Initial tau concentration
- Source location
- Connectivity between modeled brain regions
- Tau aggregation and diffusion over time
- Interactions between multiple regions of tau accumulation

## Architecture

### Backend
Python implementation of the mathematical simulation and brain-region model.

Key files include:

- `main.py`
- `simulation.py`
- `calculations.py`
- `connections.py`
- `neuron_packet.py`
- `create_tau.py`

### Frontend
HTML, CSS, and JavaScript interface for displaying and interacting with simulation results in three dimensions.

Key files include:

- `index.html`
- `simulation.js`
- `graph.js`
- `data.js`
- `menu.js`
- `styles.css`

## Research Context

The model draws on mathematical descriptions of tau pathology and spatial diffusion, including discrete representations of connectivity between modeled brain regions.

The project combined:

- Mathematical modeling
- Python simulation
- JavaScript visualization
- 3D spatial representation
- Iterative model development
